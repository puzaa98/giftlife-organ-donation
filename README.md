## 🎯 Objective

To create a web-based platform that connects organ donors with patients in need. It manages the entire lifecycle from donor registration, patient requests, auto-matching, procurement, to transplantation.

---

## ✨ Features

- ✅ User Registration with Password Strength Meter
- ✅ Secure Login / Logout / Forgot Password
- ✅ Role-Based Dashboards (Admin, Donor, Recipient, Hospital)
- ✅ Donor Profile Management (Blood Group, Age, Organs)
- ✅ Recipient/Patient Request with Vitals
- ✅ CRUD Operations (Create, Read, Update, Delete)
- ✅ Auto-Match Algorithm with Compatibility Score
- ✅ Procurement with Ambulance Tracking
- ✅ Search & Filter
- ✅ Notifications
- ✅ Admin Panel (User Management, Hospital Verification)

## ⚙️ Setup Instructions

1. Install XAMPP
2. Start Apache and MySQL
3. Create database: `organ_db`
4. Import `database.sql` in phpMyAdmin
5. Copy `organ` folder to `C:\xampp\htdocs\`
6. Open browser: `http://localhost/organ/register.php`
